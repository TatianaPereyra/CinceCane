# CineCane 

Aplicación móvil desarrollada para Android 
que permite buscar y explorar películas utilizando la API de **The Movie Database (TMDB)**.

## Características Principales

- **Pantalla de Inicio**: Muestra las películas más populares del momento.
- **Buscador de Películas**: Busqueda de peliculas por su titulo.
- **Detalle de Película**: Muestra informacion detallada de una pelicula, incluyendo sinopsis, puntuación, votos, géneros, duración y fecha de lanzamiento.
